# McSplit 麦麦拼单精算师

> 办公室多人拼单，一句话搞定询价、薅券、AA 算账。

McSplit 是一个基于麦当劳官方 MCP Server（mcd-mcp）构建的 AI 拼单助理。它把「多人拼麦当劳」这件小事里最烦的三件事——**逐个问吃什么、手动比价凑券、按人头算账**——压缩成一段对话。

## 核心功能

| 功能 | 说明 |
|---|---|
| 🗣️ 对话式收集订单 | 一句话提供门店、自取/外送、每个人的餐点即可启动 |
| 📋 订单智能解析 | 整理为结构化表格；不确定的餐品用 ❓ 标注并给出候选项，绝不瞎猜 |
| 💰 实时价格查询 | 所有价格通过 mcd-mcp 实时查询，禁止凭印象报价 |
| 🎟️ 优惠券运筹 | 自动扫描卡包+门店可用券，枚举合法方案，推荐最优组合并验证最终价 |
| 🧾 AA 分摊账单 | 品类券归点餐人、满减按原价比例、配送费按人头；精确到 0.1 元向上取整 |

## 快速开始

1. **配置 MCP Server**：复制 `mcp-config.example.json`，将 `${MCD_MCP_TOKEN}` 替换为你自己的 mcd-mcp Token，写入你的 AI 客户端 MCP 配置。
2. **载入 Skill**：将拼单工作流程（见仓库根目录 `McSplit 麦麦拼单精算师.md`）作为项目 Skill / 系统提示加载。
3. **开始拼单**：对 AI 说一句话，例如——

```
帮我组织拼单，门店在上海市静安区南京西路1号，外送。
参与者：
- 小明：麦辣鸡腿堡套餐（可乐换无糖）
- 小红：双层吉士堡 + 橙汁
- 小李：薯条×2
- 我自己：麦辣鸡腿堡单品 + 麦咖啡美式中杯不加糖
```

## 技术架构

```
用户（自然语言）
   │
   ▼
AI Agent（加载 McSplit Skill）
   │  五步工作流：收集 → 确认 → 询价 → 用券 → 分摊
   ▼
mcd-mcp Server（https://mcp.mcd.cn，Streamable HTTP）
   │
   ├─ 地址层  delivery-query-addresses / delivery-create-address
   ├─ 门店层  delivery-query-stores / query-nearby-stores
   ├─ 菜单层  query-meals / query-meal-detail
   ├─ 优惠层  query-store-coupons / query-my-coupons / available-coupons
   ├─ 算价层  calculate-price（含券验证）
   └─ 下单层  create-order
```

- **协议**：MCP over Streamable HTTP，Bearer Token 鉴权
- ** Skill 层**：Markdown 声明式工作流，可被任何支持 Skill 的 Agent 宿主加载
- **工程细节**：用券商品的 productCode 须使用券面返回编码（如 `1440` 而非菜单码 `901440`），否则算价接口报 `600012`
